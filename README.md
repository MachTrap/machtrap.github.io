# machtrap

Personal developer site built with Astro, TypeScript, and WebGL2. Available in English and Russian.

[Visit the site](https://machtrap.github.io)

## Development

Node.js 22+.

```sh
npm ci
npm run dev
```

```sh
npm run check
npm test
npm run build
```

Pushes to `main` deploy automatically through GitHub Pages.

Fonts: IBM Plex Sans and Mono ([SIL Open Font License](public/fonts/OFL.txt)).
